タロット・デュエル 実装内容（README）
==========================================

■ 概要
タロット全78枚を使う、1対1（対AI）のブラウザ対戦カードゲームです。
大アルカナ22枚は「ユニット（召喚）」、小アルカナ56枚は「魔法・支援」として使います。
1つのHTMLファイル（tarot-duel-v2.html）で動き、iPhone/PCのブラウザで遊べます。

■ タイトル画面
・フリー対戦／ストーリーモード／アーケードモード／サウンドモード／マニュアル（遊び方）のボタンが並ぶ。
・マニュアル：遊び方（基本ルール・元素相性・旅路ボーナスなど）を全2ページで説明する。タイトルとは別画面。

■ ゲームモード
1. フリー対戦
   ・デッキ構築：大アルカナを5〜8枚、小アルカナのスートを2つ選ぶ（小アルカナは15枚）。「おまかせ」もあり。
   ・難易度：弱い／普通／強い（敵のライフは 12／16／20。強いほど判断が賢くなる）。
   ・敵の大アルカナは、自分と同じ枚数。
2. ストーリーモード（全22章「愚者の旅」）
   ・大アルカナ1枚が1章に対応。ボスごとに固有ルールがある。
   ・第1章はチュートリアル（画面の「チュートリアル」欄が、操作に合わせて案内を切り替える）。
   ・第1〜4章は、愚者(0)・魔術師(I)・女教皇(II)・女帝(III)を最初から持っており、大アルカナは増えない。
   ・第5章以降は、勝つたびにボスのカードが仲間になり、仲間は全部デッキに入る。
   ・山札の枚数制限なし：大アルカナ（仲間全部）＋小アルカナ56枚。敵も同じ枚数の大アルカナ＋小アルカナ56枚。
   ・各章：あらすじ（イラスト付き）→対戦→クリア画面。進行はブラウザに保存される。
   ・ボス固有ルールの例：創造（向きを入れ替え）／直感（相手の手札が1枚見える）／忍耐（受けるダメージ-1）／
     再生（最初に倒れるユニットが体力1で踏みとどまる）／幻影（手札の向きが入れ替わる）／完成（召喚時に盾）など。
   ・魔術師の「創造」：自分のターンに1回、手札の小アルカナ1枚の向きを入れ替えられる。
3. アーケードモード（全5戦）
   ・自分のデッキで連続5戦。弱い相手から段々強くなる。
       第1戦 弱い(ライフ12) → 第2戦 弱い(15) → 第3戦 普通(16) → 第4戦 普通(19) → 第5戦 強い(20)
   ・5連勝で「アーケード制覇！」。
   ・負けると「CONTINUE?」が出て、10から1秒ごとにカウントダウン。
     コンティニュー（同じ戦いをやり直す）／あきらめる／0になるとGAME OVER。
   ・投了した場合は、コンティニューなしでそのままGAME OVER。
   ・コンティニュー画面では、専用のオリジナル曲（差し迫った雰囲気）が流れる。
4. サウンドモード
   ・タイトルのボタンから入れる。BGM全5曲（神秘／戦闘・疾走／戦闘・行進／旅路／コンティニュー）を試し聞きできる。

■ 基本ルール
・ライフ20（敵は難易度で異なる）。相手のライフを0にすれば勝ち。
・気力は毎ターン1ずつ増える（最大10）。画面では気力を丸（●が使える、○が使用済み）で表示（ステータスの上・右端）。
・手札をタップ→「召喚する／使う」。ユニットは場に最大4体。
・召喚直後と攻撃後のユニットは横向き（タップ）になり、次の自分のターンに起き上がる。
・相手のユニットがいる間は、相手のライフには直接攻撃できない。
・山札が尽きて引くと、1、2、3…と増えるファティーグダメージを受ける。
・攻撃力0のユニットは、自分のターン開始時に1、2、3…と増えるダメージを受ける（ファティーグ）。
・投了ボタンあり（確認つき）。

■ カードの仕様
・大アルカナ22枚：各カードに気力・攻撃・体力・元素・能力・キーワード・相性・台詞・絵柄がある。
・小アルカナ56枚：ワンド／カップ／ソード／ペンタクル。
  ・正位置／逆位置：引いた時に約4割が逆位置。逆位置は強さの序列が反転し、効果が変わる。
  ・強さの序列：2＜…＜10＜ペイジ＜ナイト＜クイーン＜キング＜エース（逆位置は反転）。
  ・元素相性：場の大アルカナと友好の元素なら効果+1、対立なら-1（最大±2）。
      友好：火と風・水と地／対立：火と水・風と地
  ・✦相性：大アルカナと同じ相性スートの小アルカナを使うと、追加効果が発動。
  ・各カードにキーワードを表示。
  ・追加効果（正位置の全56枚）：スートごとの基本効果に、カードの意味にちなんだ追加効果が1つ付く。
      例）ワンドのエース＝使用後、次に使うカードのコスト-1／カップの3＝味方全体の体力+1・ライフ+1／
          ソードの7＝相手の手札を1枚奪う／ペンタクルのキング＝次のターンの気力+2・ライフ+2
      ペイジ・ナイト・クイーン・キングは、人物ごとの個別の追加効果を持つ。
      カードを選ぶと、説明欄に追加効果が表示される。逆位置の小アルカナには、追加効果はない。
・旅路ボーナス：大アルカナを「前に召喚した番号+1」の順で出すと攻撃+2・体力+2（大）、
  番号が大きくなる順なら攻撃+1（小）。画面下の「旅路」には、まだ出していない自分の大アルカナのうち、直前に出した番号の次に来る番号が1つ表示され、
  それを次に出すと大ボーナスになる場合は金色で強調される。
・カード図鑑（全カードの効果を確認できる）。初めて使うカードは解説が表示される。

■ 画面・演出
・手札カード：コストは左下、大アルカナの攻撃/体力は右下。
・大アルカナ（手札・場のユニット）は、左上に番号（ローマ数字、愚者は0）を金色のバッジで強調して表示する（手札では他の数字と重ならないよう、絵柄の上の段に置く）。
・場のユニットには、状態（盾・封印・消耗・連撃）が文字で表示される。
・ドロー：カードが右から左へ流れて手札に入る。
・召喚：手札から場へ移るアニメーション＋派手なエフェクト（大アルカナと小アルカナで別の動き）。
  大アルカナ召喚時は、台詞のバナーも出る。
・ダメージ：受けたユニット／本体が揺れて赤く光り、衝撃の円・斬撃・ダメージ数が出る。盾で防ぐと「防いだ」。
・自分の本体が攻撃を受けた時だけ、画面全体が約1.5秒揺れる。
・背景：対戦ごとに火・水・風・地の背景が変わる（ボタンでオン/オフ）。
・手札の横スクロール位置は、再描画しても保持される。
・OSの「視差効果を減らす」設定の時は、アニメーションを出さない。

■ 音
・効果音：すべてWebAudioで合成（ファイル不要）。
・BGM（「♪」ボタンで切り替え）：神秘（マジシャン風）／戦闘・疾走（FF風）／戦闘・行進（ドラクエ風）／旅路（ストーリー用）。
・コンティニュー曲「最後の十秒」：アーケードのコンティニュー画面専用（通常のBGM切り替えには入らない）。
・BGM／効果音／背景は、ボタンでオン・オフ。

■ AI
・難易度ごとにAIの手札枚数・ライフ・判断の賢さが異なる（弱い：ミスが多い／強い：有利な交換を選び、強力な大アルカナ候補から選ぶ）。

■ 補足
・進行データ（ストーリーのクリア状況、背景のオン/オフ）は、ブラウザのlocalStorageに保存される。
・フリー対戦とアーケードの大アルカナの上限は、ソース内の FREE_M（現在8）で変更できる。
