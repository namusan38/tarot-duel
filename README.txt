  タロット・デュエル  README

■ 概要
タロット全78枚（大アルカナ22枚＋小アルカナ56枚）を使う、1対1の対戦
カードゲームです。大アルカナは「ユニット（召喚）」、小アルカナは
「魔法・支援」として使います。カードを遊ぶうちに、タロットの意味や
元素の関係が自然に身につくことを目指しています。

収録モード
  ・フリー対戦 ........ 自分でデッキを組んで、コンピュータと対戦
  ・ストーリーモード .. 愚者の旅（全22章）。章ごとにボスと対戦

■ 遊び方（起動）
  tarot-duel-story.html をブラウザで開くだけで遊べます。
  （インストール不要。フォントはインターネットから読み込みますが、
    つながらなくても代わりのフォントで動きます）
  音は画面を最初にタップした時から鳴ります。

■ 基本操作
  手札のカードをタップ → 「使う」「召喚する」ボタン
  攻撃        … 緑の枠の自分のユニットをタップ → 対象を選ぶ
  ターン終了  … 「ターン終了」ボタン
  図鑑        … 全カードの解説（キーワード・能力・台詞・元素など）
  投了        … 対戦を降りて負けになります
  右上のボタン… BGM（オン/オフ）／♪（曲の切替）／背景／SE（効果音）

■ 勝敗とターンの流れ
  ・相手のライフを0にすると勝ちです。
  ・ライフは自分20。相手は難易度で変わります（弱い16／普通20／強い25）。
  ・デッキは大アルカナ5枚＋小アルカナ15枚です。
  ・最初の手札は4枚。毎ターン、自分のターン開始時に1枚引きます。
  ・気力（コスト）は毎ターン1ずつ増え、最大10です。
  ・場に出せるユニットは4体までです。
  ・相手のユニットがいる間は、ライフに直接攻撃できません。
  ・ユニットは召喚直後と攻撃後は横向き（タップ）になり、次の自分の
    ターンに起き上がって攻撃できます。
  ・攻撃されたユニットは反撃します。

■ 大アルカナ（ユニット）
  22枚それぞれに、気力・攻撃・体力・元素・特殊能力があります。
  召喚時に台詞が表示されます。
  ・魔術師は「創造」を持ちます。場にいる間、自分のターンに1回、
    手札の小アルカナ1枚の向き（正位置/逆位置）を入れ替えられます。
    （カードを選ぶと「創造：向きを変える」ボタンが出ます）
  ・大アルカナと同じスートの小アルカナを使うと、そのカードの相性
    効果（✦相性）が発動します。

■ 小アルカナ（魔法・支援）
  スートごとの役割：
    ワンド（火）    … 攻撃（ダメージ）
    カップ（水）    … 回復・支援
    ソード（風）    … 妨害・戦術（敵の攻撃を下げる＋1枚引く）
    ペンタクル（地）… 防御・資源（盾＋体力）

  強さの序列（効果量とコストに影響）
    2 ＜ 3 ＜ … ＜ 10 ＜ ペイジ ＜ ナイト ＜ クイーン ＜ キング ＜ エース

  正位置と逆位置
    ・引いた時に、約4割が逆位置になります（小アルカナのみ）。
    ・逆位置では強さの序列が反転します（エースが最弱、2が最強）。
    ・効果の内容も逆位置用に変わります。
    ・手札の逆位置カードは、絵が逆さまに表示されます。

  コートカードの追加効果
    ペイジ … カードを1枚引く
    ナイト … 次のターンの気力+1
    クイーン … ライフ+3
    キング … 味方全体の体力+1
    （エースと数札には追加効果はありません）

■ 元素相性
  ワンド＝火、カップ＝水、ソード＝風、ペンタクル＝地。
    友好：火と風／水と地
    対立：火と水／風と地
  小アルカナを使う時、自分の場の大アルカナとの関係で効果量が変わります。
    友好の大アルカナが場にいる … 効果+1
    対立の大アルカナが場にいる … 効果-1
  （合計は最大±2。複数のユニットがいれば合算されます）

■ 旅路ボーナス（愚者の旅）
  大アルカナを番号順に出すと、ユニットが強化されます。
    直前に出した番号の+1を出す … 攻撃+2・体力+2（大ボーナス）
    直前より大きい番号を出す   … 攻撃+1（小ボーナス）
  愚者（0）から始めると、0→I→II…と大ボーナスを狙えます。
  自分の欄に「旅路→（次の番号）」と表示されます。

■ ファティーグ（消耗ダメージ）
  ・山札が尽きた状態でカードを引くと、ライフに1、2、3…と増える
    ダメージを受けます。
  ・攻撃力が0のユニットは、持ち主のターン開始時に1、2、3…と増える
    ダメージを受けます。

■ ストーリーモード
  愚者の旅（全22章）。大アルカナ1枚が1章に対応しています。
    第1章「旅立ち」（愚者の物語）→ 第2章 魔術師 → … → 第22章 世界
  ・章は順番に解放されます。クリア済みの章は何度でも遊べます。
  ・ボスに勝つと、そのカードが仲間（デッキに入れられるカード）に
    なります。
  ・仲間が5枚を超えると、章の前に「デッキ編成」画面が出て、入れる
    大アルカナ5枚を選べます。小アルカナは4スートからランダムに入ります。
  ・章ごとに会話、情景イラスト、BGMがあります。
  ・進行状況と編成は、ブラウザに保存されます。
    （ストーリーメニューの「進行をリセット」で消去できます）
  ・難易度：第1章は弱い、第2章は普通、第3章は強い、第4〜10章は普通、
    第11〜22章は強い。第17章以降は相手のライフが増えます（最終章は35）。

  ボス固有ルール
    第2章  魔術師  創造 … 相手が毎ターン、手札の小アルカナ1枚の向きを入れ替える
    第3章  女教皇  直感 … 相手の手札が1枚、画面上部に見える
    第4章  女帝    豊穣 … 相手のターン終了時、相手の全ユニットの体力+1
    第5章  皇帝    統率 … 相手の場に2体以上いる間、相手の全ユニットの攻撃+1
    第6章  教皇    導き … 相手は対戦開始時に手札を2枚多く引く
    第7章  恋人    結びつき … 相手のターン開始時、双方のライフ+2
    第8章  戦車    前進 … 相手のユニットは召喚したターンから攻撃できる
    第9章  力      忍耐 … 相手の全ユニットが受けるダメージ-1
    第10章 隠者    洞察 … 相手は毎ターン追加で1枚引く
    第11章 運命の輪 巡り … 相手のターン開始時、相手の全ユニットが成長する
    第12章 正義    均衡 … 相手のターン開始時、ライフが多い側が1ダメージ
    第13章 吊るされた男 試練 … 相手のターン開始時、双方ライフ-1でカードを1枚引く
    第14章 死神    再生 … 相手の最初に倒れるユニットが1回、体力1で踏みとどまる
    第15章 節制    節度 … 相手のターン終了時、相手のライフ+2
    第16章 悪魔    束縛 … 相手のターン開始時、自分のユニット1体が封印される
    第17章 塔      崩壊 … 相手のターン開始時、場のランダムなユニット1体に1ダメージ
    第18章 星      希望 … 相手のライフが半分以下になると、1度だけ+6

■ 演出・設定
  ・召喚や魔法の使用時に、大アルカナと小アルカナで別のエフェクトが出ます。
  ・BGMは4曲：神秘／戦闘・疾走／戦闘・行進／旅路。
    ストーリーでは章に合わせて自動で切り替わります。
  ・対戦画面の背景は、火・水・風・地の4種類です（ボタンでオフにできます）。
  ・端末の「視差効果を減らす」設定がオンの時は、動きの演出を止めます。

■ 保存されるデータ（ブラウザ内）
  ・ストーリーの進行と編成
  ・背景のオン/オフ
  ブラウザのデータを消すと、これらも消えます。

■ 注意・メモ
  ・カードの能力や元素の割り当ては、タロットの意味や象徴から着想した
    このゲーム独自の設計です。タロットの公式な戦闘能力ではありません。
  ・カードの絵は簡易的なアイコンです。BGMと効果音は、ブラウザ内で
    プログラムが生成しています（音源ファイルは使っていません）。
  ・まだ入っていない案：
      - 世界（XXI）到達時の特別報酬
      - 対戦後の「使ったカードの意味」振り返り画面
      - 同じ元素同士の追加ボーナス
