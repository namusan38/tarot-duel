タロット・デュエル 試作品 0.1

遊び方：
1. index.html をブラウザで開く。
2. 手札の大アルカナを選択し、「選択した大アルカナを召喚」を押す。
3. 戦場のユニットを選択し、攻撃ボタンでCPUに攻撃する。
4. 小アルカナを選択し、支援カード使用ボタンで効果を使う。
5. ターン終了でCPUが行動し、次のターンに進む。
6. 「カードの意味を学ぶ」で選択中のカードの説明を確認できる。

注意：
これは初期の動作確認用試作品です。CPUの戦闘やカードバランス、デッキルールなどは簡略化しています。
カードの伝統的な意味は一般的な解釈を簡潔にまとめたもので、カード効果はゲーム独自の設計です。
